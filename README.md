# REST API - Поиск и бронирование авиарейсов

Проект **FlightPool** — REST API для авиакомпании, разработанное на PHP с использованием фреймворка **Laravel**.

API предназначено для организации поиска авиарейсов, регистрации и авторизации пользователей, оформления бронирований и управления местами пассажиров.

## Основной функционал

- Регистрация и авторизация пользователей с использованием Bearer Token.
- Поиск аэропортов по названию города, аэропорта или IATA-коду.
- Поиск доступных авиарейсов по направлениям и датам.
- Оформление бронирований с указанием пассажиров.
- Получение информации о бронировании по уникальному коду.
- Получение списка занятых мест в самолёте.
- Выбор и изменение мест пассажиров.
- Получение списка собственных бронирований.
- Получение информации об авторизованном пользователе.

## Используемые технологии

- **PHP** — серверная разработка.
- **Laravel** — backend-фреймворк.
- **MySQL** — база данных.
- **REST API** — архитектура взаимодействия с клиентом.
- **JSON** — формат передачи данных.
- **Bearer Token** — аутентификация пользователей.

## Особенности реализации

- Валидация входящих запросов.
- Обработка ошибок и возврат соответствующих HTTP-статусов.
- Проверка доступности мест перед оформлением бронирования.
- Проверка занятости мест при их выборе.
- Защита маршрутов, требующих авторизации.
- Сохранение исходной структуры и данных предоставленной базы данных.
